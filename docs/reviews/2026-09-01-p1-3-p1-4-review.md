## Questions the review answered without a finding

Worth recording, because each was a real suspicion:

- **Node uniqueness is sound.** Dataclass equality covers every field, so two nodes that compare equal but differ semantically cannot exist.
- **Symbol edges are not silently eaten** by module aggregation: the `EdgeKind.IMPORTS` filter excludes them before `eligible` is consulted.
- **Louvain is platform-independent.** It uses `py_random_state` (`random.Random(seed)`), and canonical graph construction removes set-iteration leakage. Reversed insertion was empirically identical.
- **The insertion-order test is not tautological**: removing the `sorted()` calls would change networkx node order, which Louvain consumes.
- **Community anchors cannot collide**, since membership is a partition.

## Test quality

Build's contract tests were called *"the best in the project"* — each constructs the violation, and the constructor-bypass fixtures assert the fixture actually bypassed. But:

- **Two tests were tautological on their named axis.** `test_merge_is_order_independent` varied only the field merging canonicalizes; `test_edge_weights_are_used` asserted a key exists where the value was provably constant. Both hid a live bug.
- **The workspace parametrization covered one happy syntax per manifest kind, with no decoys** — the decoy rule un-applied to a new surface again. It hid F1 and F7.
- **Clustering quality was entirely untested.** A stub returning arbitrary per-seed partitions passed every cluster test, so a backend regression to noise would ship green. Now asserted: the planted `api` / `worker` structure must be recovered.

The lockfile-isolation tests are honest about their limits: `_render_lock` is a pure function of a frozen `Graph` that clustering never receives mutably, so "unchanged by reclustering" is **true by construction**. They are tripwires against future wiring mistakes, not proofs — which is the right thing to have, given the wiring is the risk.

## Contracts P1-5 must honour

1. **Consume `Clustering` by value; emit nothing keyed on it.** Every id in a `DiagramSpec` must be a module id or node id from `Graph`. Anchors are module ids and safe as labels; `fingerprint()`, `cohesion` and membership belong only in the rendered viewer payload.
2. **Top-level box count is not bounded by clustering alone.** F6's fix reduces shattering but a stubborn group is now diagnosed rather than split; derivation must read `SVA-C-004` and do its own capping.
3. **Impact analysis uses symbol-level REFERENCES/CALLS edges, not `module_deps`.** Barrel indirection is only correct at symbol level: a barrel in X re-exporting from Y yields `A → X` at file level, with `A → Y` existing solely as a symbol reference.
4. **Exclude `type_only=true` edges from runtime flow.** Safe now that F3 has landed.
5. **Merged `arity` means worst-case ambiguity across sites**, and `attr("sites")` is an evidence count, not a call count.
