## The finding that is about process, not code

Four waves shipped under live user feedback with no intermediate review, and
the review demonstrated, rather than suspected, that the documented failure
patterns recurred in exactly that gap:

* **The mutation lists froze while the surface tripled.** 2,500 new lines
  (sugiyama, flow, compose extraction, expansion, system deriver) with zero new
  mutation entries. Deleting the barycentric sweep, the headline of the commit
  named "Make the diagrams worth looking at", passed every test. So did
  routing every flow skip straight through the intervening columns.
* **The previous wave's fixes were unapplied to the new code, again.** Review
  #10 F2 hardened the lockfile's loading channel; the compose loader shipped
  one wave later with a hostile file killing the whole run. Review #10 F3
  keyed committed bytes to committed facts; the compose extractor reopened the
  config-module churn one wave later through a truthiness filter.
* **The determinism gates were all green while the property was false on the
  first real repository tried.** Every fixture was below the scale where
  Louvain's aggregation engages.

The protocol change that follows: **user-facing waves do not accumulate. Each
one gets its review before the next, however fast the feedback loop feels**,
because the feedback loop's speed is precisely when the recurrence rate is
highest.

## The gate that took three attempts

F3's fix was one relabelling; its **gate** was the hard part, and each failed
attempt was a §15.1 lesson recurring:

1. A synthetic 48-module fixture stayed green with the fix removed: below the
   scale where the property breaks. *A determinism gate is scoped to scale.*
2. The committed real reproducer aimed at the first-level Louvain pass stayed
   green too: measured, level 1 is stable on this graph even unfixed. The
   sensitive stage is the oversized-community **resplit**, which re-runs the
   backend over a subgraph. *A gate aimed at the wrong stage of a two-stage
   algorithm certifies the stage that was never broken.*
3. The gate now drives both stages over descovo's captured module graph
   (`tests/fixtures/louvain_seed_sensitive.json`, 36 nodes, 74 weighted edges,
   the smallest real graph observed to reproduce), and removing the
   relabelling reds it, verified by mutation.

## Promoted to the decision log

1. **A parser's exception list is what it raises in practice, not what its docstring names** (F1). A new parser of repository bytes inherits the full hostile-input posture on day one, including its library's failure modes.
2. **A truthiness filter over an open-ended field is a claim about every future producer** (F2). Guards enumerate what they accept; `if node.lang` was falsified by the very next producer to mint a new value.
3. **A determinism gate is scoped to scale and to stage** (F3). An algorithm can be deterministic on every small fixture and seed-dependent past the size where its second phase engages, and a gate aimed at the wrong phase certifies the one that never broke. A captured real graph is the fixture of record when synthesis fails to reproduce.
4. **When a commit message names a property as its point, the checklist question is "which test fails if this property is deleted", answered by deleting it** (F4). The sweep and the corridor both survived deletion under 539 green tests.
5. **User-facing waves do not accumulate unreviewed** (process). The velocity of a live feedback loop is when the documented failure patterns recur fastest; each wave gets its review before the next.
6. **Distinctness is not spread** (C3). A test asserting values differ passes a layout that crams them into a corner; assert the quantity the failure mode actually degrades.

## Riskiest remaining untested assumption

The reviewer's, accepted with its scope narrowed by the fixes: that the shipped
pipeline is byte-deterministic at scales and structures beyond the one captured
reproducer. The louvain gate is a real graph, but it is one graph; the
resplit's sensitivity was structural (a dense cycle plus heterogeneous
satellites), and nothing says descovo's shape is the only sensitive one.
Cross-OS byte comparison in CI (`render_fixture_lock` + the compare-bytes job)
now runs the full pipeline, but its fixture is small. The standing mitigation
is the relabelling itself, which removes the mechanism rather than the
instance; the standing risk is whatever other library iterates a set of names
somewhere downstream. The next real-repository onboarding should re-run the
cross-seed byte comparison as a matter of course.
