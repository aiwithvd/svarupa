A small follow-up to 2026.10.1: AI tool rules no longer go stale silently.

## New

- **Stale rules warning**: `svarupa check` now warns when the rules that
  `svarupa setup ide` wrote for an AI coding tool (the block in `CLAUDE.md`,
  `AGENTS.md` or `.github/copilot-instructions.md`, or Svarupa's own Cursor,
  Windsurf and skill files) no longer match the repository's design. It
  names the file and says to run `svarupa setup ide --update`. It is a
  warning, never a failure: in `--json` as `stale_rules`, and as a
  `::warning` annotation with `--format github`. Your text outside the
  markers and line endings never count.

## Upgrading

No action needed: `uv tool upgrade svarupa`. If `svarupa check` reports
stale rules, run `svarupa setup ide --update` and commit the result.
