Small fixes found in review, plus a sturdier release script.

## Fixes

- `svarupa explain --lang` now rejects an unknown language with a clear
  error (a typo such as `pyhton` used to print "no example" and succeed).
  `javascript` still works.
- `svarupa setup --dry-run` no longer prints "next:" steps, since nothing
  was installed.
- The GitLab `health_check` job installed by `svarupa setup ci_gitlab`
  writes a valid empty Code Quality report when the check cannot run, so
  GitLab no longer flags an unreadable report (the job still fails).
- The viewer's passport no longer confuses a box named like a built-in
  JavaScript property (for example `constructor`) with a box sentence.
- The Java examples for `endpoint-without-auth` and `large-class` in
  `svarupa explain` now compile as written.
- A rules file whose end marker comes before the begin marker gets its own
  clear error message.

## Upgrading

`uv tool upgrade svarupa`. If you use the GitLab gate, re-run
`svarupa setup ci_gitlab --update` and commit the change. Nothing else is
needed.
