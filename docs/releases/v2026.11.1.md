Two new languages, C# and Rust, and many more calls traced to their real
target in every language.

## New

- **C# support (stable).** Svarupa now reads C# projects. Diagrams,
  `graph.json`, the health grade and the design view all cover them.
  - `using` lines are linked through namespaces.
  - NuGet packages from `*.csproj` and `Directory.Packages.props` count as
    external.
  - Each project is a design unit.
  - Health checks for C#: SQL and command injection, TLS checks turned off,
    unsafe deserialization, MD5 and SHA1, CORS that allows any origin, queries
    inside loops, blocking calls in `async` methods, empty `catch` blocks, and
    the function size checks.
  - `svarupa explain` shows a C# before and after example for each of these
    checks.
- **Rust support (stable).** Svarupa now reads Rust crates and workspaces.
  - `use` and `mod` paths are linked through `Cargo.toml`, including
    workspace crates and `pub use` re-exports.
  - Methods in `impl` blocks belong to their type, even in another file.
  - Cargo dependencies count as external.
  - Test code (`#[cfg(test)]`, `#[test]`) is not graded.
  - Health checks for Rust: SQL built with `format!`, shell commands, TLS checks
    turned off, MD5 and SHA1, CORS that allows any origin, queries inside loops,
    blocking calls in `async fn`, and the function size checks. `svarupa
    explain` has Rust examples.
- **Typed parameters and locals.** A call like `svc.place()` or
  `ctx.user_id()` now links to the real method when `svc` or `ctx` has a
  written type. The type can come from a function parameter or an explicitly
  typed local, such as `let x: Repo` or `Repo r = ...`. This works in Rust, Go,
  Java, C#, TypeScript and Python.
  - On the benchmark this took a real Rust app from 77% to 93% of its expected
    facts.
  - Types are looked up only where the language itself would look, so a
    same-named class elsewhere in the repo never gets the link.
  - Locals with no written type (`var x = new T()`, `x := NewT()`) are not
    guessed.

## Fixes

- A call to a method that a class overrides, or that implements an interface
  method, now links to that class's own method. Before, it showed as one of
  two "maybe" targets.
- The health grade of a C# repository counts its C# lines. Before, a pure
  C# repo could show 1 line of code and a wrong grade.

The benchmark now has 15 real repositories, including 2 in C# and 2 in Rust.
`docs/health.md` lists what each language does not resolve yet.

## Upgrading

`uv tool upgrade svarupa`, then run `svarupa .` again.

- **If you commit an architecture lockfile:** run `svarupa . --lock` and
  commit `architecture.lock` in its own pull request.
  - **Python, TypeScript, JavaScript, Go and Java repos:** only the version
    line changes.
  - **Repos with C# or Rust code:** these modules and their dependencies
    appear in the lockfile for the first time, so review that diff once.
- **If you use the CI gate:** re-run `svarupa setup ci_github --update` (or
  `ci_gitlab --update`) to move the pinned version, and commit the change.
- **Expect new health findings:** `graph.json` and `REPORT.md` now show more
  call links than before. Health findings that depend on call links can
  change, so expect some new findings on the first run.
